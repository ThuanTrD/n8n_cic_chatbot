# Workflow Skeleton

Facebook webhook
to event classification and idempotent customer-message persistence
to bounded wait/admin detection
to conversation/config validation
to five-customer-turn context plus persistent profile
to organization-scoped product/evidence retrieval
to semantic router with deterministic field reconciliation
to evidence policy and profile upsert
to quote/lead/handoff/feedback action branches
to model answer through serialized gateway
to verifier/retry and deterministic safety guards
to URL-safe Messenger formatting
to idempotent response persistence and send
to human handoff polling with bot-message exclusion
to terminal AI/HUMAN state.

Recovery uses idempotency keys, bounded retries, inactive rollout and import rollback.
