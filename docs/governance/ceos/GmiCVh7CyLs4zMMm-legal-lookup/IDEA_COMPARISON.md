# Idea Comparison

## Option A — Reuse the current document/version/chunk corpus
Add legal classification, organization-wide retrieval, provenance fields and policy/verifier gates. This is compatible, reversible and requires no migration. Selected for this readiness slice.

## Option B — Add a dedicated legal corpus and immutable legal-version schema
Provides stronger lifecycle and authority guarantees, but requires a migration, ingestion UI/worker and explicit retention/authority decisions. Deferred until actual documents and governance fields are supplied.
