# Legal Document Supply Contract

Each supplied document should carry:

- organization/workspace owner;
- stable document ID and immutable version;
- document type (`law`, `decree`, `circular`, `license`, `certificate`, `contract`, or other controlled value);
- exact title and document/reference number;
- issuing authority;
- issued date, effective date and expiry/repeal date when applicable;
- current/superseded status and superseding document reference;
- page/article/section lineage per chunk;
- source URL or original-file reference and content hash;
- access classification and authorized audience.

Missing metadata is not guessed. A document without verified current-effect metadata may be summarized, but the chatbot must state that current legal effect still needs verification.
