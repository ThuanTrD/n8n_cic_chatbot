# Preliminary Definition of Done

Success: exact input limits match flow 2; only six context nodes and two webhook-enable flags change; production publishes the new flow-1 version; GET/POST registration and Facebook challenge pass; sanitized Git backup passes.

Failure: production switches to Hermes, model/output settings change, workflow structure differs, or webhook registration fails.

Forbidden: exposing secrets, changing the workstation, or modifying unrelated workflows.
